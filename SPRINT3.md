## Task Status Definitions 
- Not Started: work has not begun.
- In Progress: Assigned member activly working on task
- Review: member has submitted the work and is waiting for it to be checked
- Changes Required: issues in task identified and improvements need to be made
- Completed: work has beend reviewed and meets the criteria of sprint 3

## Review Process

when a task is submitted:

1. Task owner changes its status to Review.
2. Project manager checks the submitted work.
3. feedback and required improvements are recorded in Review Notes.
4. Task owner addresses the issues identifyied and resubmits the work.
5. Task is marked cCompleted once the deliverable meets the requirments
